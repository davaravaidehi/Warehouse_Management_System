# Warehouse Management System

## 📌 Project Overview

The **Warehouse Management System** is a Python-based desktop application developed to manage warehouse operations efficiently. It provides an easy-to-use graphical interface to manage customers, purchases, sales, inventory, payments, and reports.

## 🚀 Features

- User Login System
- Dashboard Management
- Customer Management
- Purchase Management
- Purchase Return Management
- Sales Management
- Sales Return Management
- Stock Management
- Payment Management
- Company Management
- Bill Generation
- Report Management
- Forgot Password Functionality

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend Programming |
| Tkinter | Graphical User Interface |
| MySQL | Database Management |
| Pillow (PIL) | Image Processing |
| Git & GitHub | Version Control |
| PyCharm | Development Environment |

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/davaravaidehi/Warehouse_Management_System.git
```

### 2. Navigate to Project Directory

```bash
cd Warehouse_Management_System
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment (Windows)

```bash
venv\Scripts\activate
```

### 5. Install Required Libraries

```bash
pip install pillow mysql-connector-python
```

Install any other libraries required by your project.

### 6. Configure MySQL Database

- Install and start MySQL Server.
- Create the required project database.
- Configure your MySQL connection settings in the application.
- Import your database backup or execute your database SQL script if available.

**Note:** Do not upload your MySQL password or other sensitive database credentials to GitHub.

### 7. Run the Application

```bash
python main.py
```
